# ✏️ Spell Correction

> NLP spell-correction model

![Python](https://img.shields.io/badge/Python-1f6feb?style=flat-square) ![spello](https://img.shields.io/badge/spello-1f6feb?style=flat-square) ![Regex](https://img.shields.io/badge/Regex-1f6feb?style=flat-square)

## 📌 Overview
A spell-correction model built with spello, with regex-based preprocessing to clean noisy text before correction.

## ✨ Features
- Regex text normalization
- Trainable spell-correction model
- Corrects full sentences

## 🛠️ Tech Stack
Python, spello, Regex

## 🚀 Getting Started
```bash
pip install -r requirements.txt
python correct.py "thsi is a smple sentense"
```
